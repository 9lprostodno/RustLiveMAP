# Rust Live Map

Десктопное приложение для администраторов Rust-серверов: живая карта с игроками и базами, статистика, чат,
консоль, команды игроков, задания по расписанию и доступ к файлам сервера. Работает по RCON (WebSocket).

Версия 1.0.0 · Windows 10/11 (PySide6)

> Это сторонний проект, он никак не связан с Facepunch Studios и игрой Rust.

## Возможности

**Карта**
- Игроки и базы (шкафы) на карте в реальном времени, цвет игрока по ID его команды, красный — без команды.
- Карта берётся из файла `.map` в папке сервера (локально, SMB, FTP/FTPS или SFTP) и рисуется на вашем компьютере,
  заодно извлекаются подписи монументов. Если папки сервера нет, можно выбрать `.map` или готовый PNG,
  запасной путь — команда сервера `world.rendermap`.
- Размер карты меняется каждый вайп: он определяется автоматически (из имени файла и `server.worldsize`).
- Heatmap: передвижение и убийства игрок-игрок, метки событий, архив карт прошлых вайпов.
- Карту можно вывести на весь экран или на другой монитор (плавающая кнопка в углу карты).

**Игроки и команды**
- Список игроков онлайн и всех, кого видели за вайп, карточка игрока (профиль, убийства и смерти).
- Вкладка «Команды»: состав команд по `global.teaminfo`, лидер, онлайн; двойной клик открывает окно команды
  с составом и историей командного чата.
- Правый клик по игроку онлайн: показать на карте, передвижения, **телепортировать к…** (команда `teleport`).

**Сервер**
- Игровой чат и консоль сервера с вводом команд, статистика из консоли (убийства, смерти, сессии, ивенты).
- Меню «Задания»: команды в консоль по расписанию (каждый день, один раз, периодически; `${playerCount}`
  подставляет число игроков). Задания выполняются, пока программа запущена и подключена.
- «Файлы сервера»: просмотр, скачивание, загрузка, правка текстовых файлов, переименование, создание папок,
  удаление — по SMB, FTP/FTPS и SFTP (подходит и для сервера на Linux).
- Несколько серверов: у каждого свой профиль со статистикой, картой и настройками.

## Установка и запуск из исходников

Нужен Python 3.11 или 3.12.

```bat
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
python rust_live_map.py
```

## Сборка exe

```bat
build_exe.bat
```

Результат — `dist\RustLiveMap.exe`: один файл, данные программа хранит рядом с ним (`config.json` и папка `data`).

## Настройка

1. «⚙ Настройки»: адрес RCON, порт и пароль сервера (в `server.cfg`: `rcon.port`, `rcon.password`,
   `rcon.web 1`).
2. Для карты из файла `.map` включите «Папка сервера» и укажите путь к ней, например
   `D:\Server\rustds` или `\\server-pc\rust` (SMB), либо адрес FTP/SFTP. Программа сама найдёт
   `server\<identity>\proceduralmap.*.map`.
3. При первом запуске без настроек программа не подключается к сети и сразу открывает окно настроек.

Для получения HP игроков можно использовать плагин `LiveMapData.cs` (команда `livemap.players`):
стандартный `playerlist` часто отдаёт Health = 0.

## Безопасность и приватность

- Пароли (RCON, FTP/SSH) хранятся в `config.json` зашифрованными средствами Windows (DPAPI) и привязаны к
  вашей учётной записи Windows. Это защищает файл при копировании, но не от вредоносной программы,
  запущенной под тем же пользователем. На других ОС шифрования нет.
- RCON передаётся по `ws://` без шифрования: не открывайте RCON-порт в интернет, используйте локальную сеть
  или VPN.
- FTPS работает без проверки сертификата сервера. Для SFTP отпечаток ключа сервера запоминается при первом
  подключении и дальше сверяется.
- Программа сохраняет данные игроков: SteamID, ники, IP-адреса из логов сервера, позиции для Heatmap, чат.
  Всё лежит локально в `data` рядом с программой. Не публикуйте и не передавайте эту папку и `config.json`;
  если у вас есть пользователи из ЕС, учитывайте, что IP-адреса — персональные данные.
